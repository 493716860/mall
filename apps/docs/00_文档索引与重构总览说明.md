# 芋道 Mall 全套重构与迁移权威文档库

> 对应目标仓库路径: [493716860/mall/tree/main/apps/docs](https://github.com/493716860/mall/tree/main/apps/docs)

本目录独立归类保存了 **微信小程序端 (`apps/miniapp`)** 与 **WEB 运营后台 (`apps/admin`)** 重构所需的所有权威规范文档与数据库 SQL 脚本，方便使用任何后端语言（如 Go, Node.js, Python, Rust, C# 等）进行等效重构。

---

## 📁 归类文档目录索引

| 文件名称 | 说明与用途 |
|---|---|
| 📄 **`01_API全量接口规范文档.md`** | 涵盖 **185 个 REST API 接口**（小程序 72 个 + 运营后台 113 个）的 URL 路径、请求参数、返回 JSON 报文与数据落库关联表 |
| 🗄️ **`02_数据库表结构全量字典文档.md`** | 涵盖保留的 **85 张核心物理数据表** 的全字段数据字典说明、主外键索引约束与业务逻辑 |
| 🛢️ **`03_数据库一键建表SQL.sql`** | 全量 85 张数据表的纯 MySQL DDL 建表 SQL，可直接在数据库命令行导入建库 |
| 🧹 **`04_清理多余表SQL脚本.sql`** | 用于在现有全量芋道 MySQL 数据库中一键清空 BPM(Flowable)、CRM、ERP、AI 大模型和报表等多余表的 DROP SQL |
| 👑 **`05_会员中心专项API与数据表说明.md`** | 专门针对会员中心（VIP 等级、成长值、积分变动、每日签到打卡、会员分组与标签）的 35 个 API 与 11 张数据表专项说明 |
| 💡 **`06_跨语言重构最佳实践与避坑指南.md`** | 跨语言重构的 6 大避坑锦囊（防超卖原子 SQL 扣库存、金额单位【分】防护、JWT Token 解析、订单状态机） |
| 🐹 **`07_Go_Gin重构指南与代码模版.md`** | 专门面向 **Go + Gin + GORM + Redis** 架构的开箱即用重构指南与目录骨架模版 |

## 🏛️ Monorepo 整体项目结构

```text
493716860/mall/
└── apps/
    ├── miniapp/      # 微信小程序前端 (Uniapp / Vue3)
    ├── admin/        # WEB 运营后台前端 (Vue3 / Element Plus)
    ├── server-gin/   # 基于 Go + Gin + GORM 开发的高性能后端 API 服务
    ├── server/       # 原版精简后的 Java (Spring Boot) 后端服务
    └── docs/         # [本重构与迁移权威文档库]
```
